โปรเจกต์ Arduino เป็นโครงการ  open-source  ในรูปแบบ  Electronics Platform จึงสามารถทำให้  ออกแบบอุปกรณ์ได้ง่าย
สรุปได้ว่า Arduino เป็นโครงการที่ทำให้การเรียนรู้เรื่องระบบคอมพิวเตอร์ ได้แก่  input/output computor   เป็นเรื่องที่ง่ายขึ้น   
Input ของ Arduino คือ sencer  เช่น  light, color, sound และเซ็นเซอร์อื่นๆ
โดยเริ่มต้นจากการต่ออุปกรณ์และรับข้อมูลเข้ามา จากนั้นทำการ เขียนโปรแกรม  และทำการ  output  ออกไปยังอุปกรณ์ต่างๆ เช่น LED, LCD  
ซึ่งสามารถนำโปรเจกต์เหล่านี้ ไปพัฒนาต่อยอดเป็น  สถานีวัดอากาศ  
Arduino มีรูปแบบเป็น  Electronics Board  แต่ตัวที่นิยมใช้กันคือรุ่น  ESP32, ESP8266     
บอร์ด Arduino สามารถใช้แหล่งจ่ายไฟจากภายนอกในส่วนของ  ภาคจ่ายไฟ  ได้แก่  VIN ในการรับไฟฟ้าจากภายนอก ต่อมาคือ  5V ใช้จ่ายไฟแรงดัน 5V และ 3.3V และ  GND  คือขากราวด์     
Arduino มีพอร์ตสำหรับการ Input/Output ในรูปแบบดิจิทัล จำนวน 14 ขา ตั้งแต่   0 - 13  ทำหน้าที่  input/output  และมีพอร์ต Input รูปแบบแอนาล็อก จำนวน  6 ขา ตั้งแต่   A0 - A5  ทำหน้าที่  แปลงค่าจาก A -> D ตั้งแต่  0 - 1023     
ส่วนที่เปรียบเสมือนสมองในการควบคุมการทำงานหลัก เรียกว่า  สมอง  โดยทำหน้าที่คล้ายกับ  CPU   
 การควบคุมซอฟต์แวร์หรือเขียนโปรแกรมให้กับ Arduino จะใช้โปรแกรม  Arduion ide  โดยใช้ภาษาคอมพิวเตอร์  C/C++  ซึ่งประกอบไปด้วยฟังก์ชันหลัก ได้แก่ 1)  setup  ทำหน้าที่  ประกาศค่าเริ่มต้น  และ 2)  loop  ทำหน้าที่  ทำตามโปรแกรมที่เขียนไว้แบบวนซ้ำ
